# PS3-eye-Web-Tester
**Warning!** This html website was made (unfortunately) entirely by Claude.ai.
This is a html website that allows everyone (even Mac users!) to test out their ps3 eye cameras! Allows multiple cameras to be used!
***Known issues:***
-adding more than 1 camera in 640x480 might cause lags if your bandwidth is too low. I recommend you don't use USB hubs (e.g. USB 2.0 hubs) but without any hubs it works perfectly.
